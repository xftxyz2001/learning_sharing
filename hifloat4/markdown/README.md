## 摘要

本文介绍了HiFloat4 (HiF4)，一种专为深度学习设计的块浮点数据格式。每个HiF4单元将64个4位元素与32位共享缩放元数据打包在一起，平均每个值占用4.5位。元数据指定了三级缩放层次结构，在捕获组间和组内动态范围的同时提高了表示空间的利用率。此外，64元素的大组大小使矩阵乘法能够以高度定点方式执行，显著减少了硬件面积和功耗。为了评估所提出的格式，我们在多个语言模型上进行了推理实验，包括LLaMA、Qwen、Mistral、DeepSeek-V3.1和LongCat。结果表明，在多个模型和不同下游任务上，HiF4实现了比最先进的NVFP4格式更高的平均精度。

**关键词:** 块浮点格式, 大语言模型, 深度学习, 推理

## 1. 引言

近年来，大语言模型（LLM）的快速发展加剧了计算吞吐量、内存容量和能源效率之间的权衡。这些挑战促使学术界研究低精度数据格式作为一种有前景的解决方案。几种新兴的8位格式，包括FP8、HiF8和MXFP8，已经部署在商业硬件产品中以加速深度学习工作负载。然而，随着模型规模和上下文长度的不断扩大，低精度格式的探索自然地向4位前沿发展。尽管MXFP8作为一种块浮点（BFP）格式在训练稳定性方面进行了性能权衡，但BFP目前似乎是4位表示最实用的途径。因为只有通过更有效地利用局部数据中的指数冗余，才能进一步降低位宽。

### 1.1 三种有影响力的4位BFP设计

#### MX4: 共享微指数

为了表征组内变化，微软和Meta提出了MX4格式，它在共享的8位指数基础上增加了8路1位微指数，形成了两级层次缩放结构。然而，由于MX4使用16的组大小，元数据产生了相对较高的开销，每值1位。为了保持平均存储低于每元素5位，组内符号幅度格式必须从4位减少到3位，导致平均存储成本为每值4位。这种减少最终导致MX4的精度甚至低于普通的4位BFP格式。因此，AMD的Versal AI Edge系列只采用了相关的MX6和MX9格式，放弃了MX4。总之，MX4展示了共享微指数在捕获组内变化方面的概念价值，然而，由于小组大小导致的元数据成本阻碍了该格式实现实际精度和效率。

#### MXFP4: 独立微指数

OCP-MXFP4为每个元素分配一个独立的2位微指数，实现更精细的组内变化。通常，4位组内格式是符号幅度S1P2，其中S表示符号位，P之前的1表示1位整数部分，P之后的2表示2位小数部分（P是二进制点）。这相当于浮点风格中的常见E1M2，其中符号位通常省略。E1M2最多提供3位有效位数，但动态范围有限，仅为log2(1.75/0.25) = 2.81个二进制度。MXFP4用E2M1替换E1M2，牺牲1位有效位数以引入2位微指数，从而将动态范围扩展到log2(6/0.5) = 3.58个二进制度。组大小也扩大到32，平均存储成本为每值4.25位。MXFP4已被多家硬件供应商采用，包括Nvidia、AMD和华为。然而，现在普遍认为MXFP4在应用于激活和权重时会遭受显著的精度下降。因此，它目前仅用于仅权重量化，如OpenAI的GPT-OSS，导致大量4位计算能力未被使用。总之，MXFP4在有效位精度和组内动态范围之间引入了新的权衡，但仍然未能充分发挥4位BFP的潜力。

#### NVFP4: 浮点缩放

除MXFP4外，Blackwell架构还支持专有NVFP4格式，它利用E2M1优于E1M2的优势，并引入了两项更改。首先，2的幂次方缩放无法保证将每个组的峰值幅度归一化到E2M1的可表示上限，浪费了组内动态范围。NVFP4用细粒度的FP8-E4M3浮点缩放替换它，充分利用E2M1的表达空间。其次，NVFP4采用与MXF4相同的16元素组大小，与MXFP4相比，平均存储成本从4.25提高到4.5位/值，但有效减少了异常值驱动的量化误差。因此，NVFP4比MXFP4实现更好的精度，可用于权重和激活，从而初步解锁了实用的4位BFP计算能力。然而，这些好处是以两个沉重的成本为代价的。首先，E4M3的动态范围不够宽。NVFP4需要额外的基于软件的每张量缩放（PTS）用于推理和训练，在格式转换期间导致性能下降。其次，考虑到与8位格式相比更高的计算能力，将浮点缩放与小组大小配对会导致矩阵计算单元的大量面积和功耗开销。总之，NVFP4采用浮点缩放来充分利用组内动态范围，尽管付出了大量硬件和软件成本。

从综合角度来看，前面的分析强调了设计4位BFP格式的固有复杂性。MX4和MXFP4使用不同的微指数机制表征组内变化，而NVFP4进一步强调最大化组内动态范围利用率的重要性。每种方法都在多个设计维度上进行权衡，例如元数据开销、组大小、有效位精度以及组内和组间动态范围。尽管NVFP4适用于权重和激活，但其在精度、组间动态范围和硬件效率方面的局限性仍然很明显。这些缺点凸显了实现实用且高效的4位BFP计算的持续挑战。

通过多轮分析和迭代，我们确定了合适的技术切入点，并提出了一种新的4位BFP格式HiF4。与最先进的技术相比，HiF4提供更高的精度、更宽的组间动态范围（适用于推理和训练）以及更低的硬件成本。在本文中，我们描述了HiF4的规范，包括格式定义和转换。然后，我们展示了不同4位BFP格式之间的量化误差和点积计算流程的比较。最后，报告了大量LLM推理实验结果，以证明HiF4的可行性和优势。

## 2. HiFloat4格式

本节系统描述所提出的4位BFP格式HiF4，并详细介绍其结构组件。然后，我们介绍从BF16到HiF4的转换算法，以及建议的硬件支持。

### 2.1 格式定义

如图所示，一个基本的HiF4单元由32位共享缩放元数据和64个4位组内元素组成，平均每个值占用4.5位。以下详细定义每个组件。

#### 2.1.1 缩放元数据

元数据定义了三级缩放层次结构。

**第一级（E6M2）**是一种专门设计的无符号8位浮点格式。此缩放提供跨组的宽动态范围，并将每个组的峰值幅度归一化到剩余层次结构的可表示上限，确保充分利用组内动态范围。表2-1总结了E6M2的编码细节。我们为指数字段分配6位，偏置为48，为尾数字段分配2位，其中一个隐藏整数位设置为1。E6M2编码NaN（非数字），但不编码其他特殊值如无穷大或零。同时，仅支持正常模式。因此，如果我们将无偏置指数表示为E，尾数表示为M，则HiF4中使用的E6M2数应解释如下：

$$X = 2^{E} \times 1.M$$

**第二级（E1_8）**和**第三级（E1_16）**分别实现为8路和16路1位微指数，通过细化局部指数差异来扩展组内动态范围，有效减轻异常值的影响并抑制量化误差。微指数E1直接编码1和0，表示非常细粒度的2的幂次方缩放因子。

在这种层次缩放方案中，第一级E6M2因子提供连接到所有第二级微指数的全局基础缩放。每个第二级E1进一步连接到两个相邻的第三级微指数，而每个第三级E1又连接到其局部组内的四个连续4位元素。所有三级缩放元数据占用32位，分布在64个组内元素上，导致每值额外开销为0.5位。

#### 表2-1: E6M2和S1P2编码细节

| 特性 | 无符号FP8-E6M2 | 符号幅度S1P2 |
|------|---------------|-------------|
| 指数偏置 | 48 | N/A |
| 无偏指数范围 | [-48, 15] | N/A |
| 无穷大 | N/A | N/A |
| 零 | N/A | S$0.00_2 = \pm 0.00$ |
| NaN | $111111\_ 11_2$ | N/A |
| 最大值 | $111111\_10_2 = 2^{15} \times 1.50$ | S$1.11_2 = \pm 1.75$ |
| 最小值 | $000000\_00_2 = 2^{-48} \times 1.00$ | S$0.01_2 = \pm 0.25$ |

#### 2.1.2 元素编码

HiF4使用符号幅度S1P2表示对4位组内元素进行编码。在这种SXPY表示法中，S表示符号位，P表示二进制点。P前面的值X表示X位整数部分，而P后面的值Y表示Y位小数部分。S1P2的编码细节总结在表2-1中。从概念上讲，S1P2等同于浮点表示中的E1M2格式；然而，我们采用S1P2表示法，因为它更直观易解释。

#### 2.1.3 表示值

由于我们已经详细阐述了每个组件，现在可以将HiF4单元作为一个整体来看待，并计算其表示值。

令$\{S1P2\}_i$表示第i个组内元素值，其中i $\in$ [1, 64]。令$\{E1_8\}_j$表示第二级缩放元数据中的第j个微指数，其中j $\in$ [1, 8]。类似地，令$\{E1_16\}_k$表示第三级缩放元数据中的第k个微指数，其中k $\in$ [1, 16]。最后，令$\{V_i\}_{i=1}^{64}$表示HiF4组中的64个实数。基于这些定义，HiF4单元的每个值可以表示如下：

- 如果$E6M2 = NaN$，则对于所有i $\in$ [1, 64]，$V_i = NaN$
- 否则，
  $$V_i = E6M2 \times 2^{(\{E1_8\}_{\lceil i/8 \rceil} + \{E1_16\}_{\lceil i/4 \rceil})} \times \{S1P2\}_i$$

除全局基础缩放E6M2之外的部分表示HiF4单元可以覆盖的组内动态范围：最大正值为$2^{(1+1)} \times 1.75 = 7$，而最小正值为$2^{(0+0)} \times 0.25 = 0.25$。因此，HiF4可用的组内动态范围为log2(7/0.25) = 4.81个二进制度。

| 局部动态范围 | 4.81 binades | 3.58 binades |

### 2.2 格式转换

算法说明了将64个BF16数据向量转换为HiF4单元的计算流程。类似的转换过程适用于其他高精度格式，如FP32和FP16。

**算法: 从BF16转换到HiF4**

```
输入: 64长度的BF16向量 V64
输出: HiF4单元: E6M2, E1_8, E1_16, S1P2_64

// 阶段1: 三级树归约
for i = 1 to 16:
    V16[i] = max(|V64[4*i-3 : 4*i]|)

for i = 1 to 8:
    V8[i] = max(V16[2*i-1 : 2*i])

Vmax = max(V8)

// 阶段2: 导出三级层次缩放元数据
SF_BF16 = Vmax × (1/7)_BF16
E6M2 = BF16_to_E6M2(SF_BF16)
E6M2_REC = E6M2_REC_to_BF16(E6M2)
E1_8 = (V8 × E6M2_REC ≥ 4) ? 1 : 0

for i = 1 to 16:
    E1_16[i] = (V16[i] × E6M2_REC × 2^(-E1_8[⌈i/2⌉]) ≥ 2) ? 1 : 0

// 阶段3: 计算64个组内元素
for i = 1 to 64:
    V64_scaled[i] = V64[i] × E6M2_REC × 2^(-E1_8[⌈i/8⌉]) × 2^(-E1_16[⌈i/4⌉])

S1P2_64 = BF16_to_S1P2(V64_scaled)
```

格式转换算法分解为三个连续阶段：

**阶段1**对64个BF16输入执行三级树归约：
- 在第一级，相邻的4个元素组并行比较，产生16个局部最大绝对值。
- 第二级将16个最大值两两归约为8个值。
- 最后一级获得8个结果中的全局最大绝对值。

**阶段2**导出三级层次缩放元数据：
- 计算第一级缩放因子，其中7是组内结构可以表示的最大绝对值，为避免性能下降，常数除法被其倒数乘法代替。然后需要专用的BF16到E6M2指令将缩放量化为E6M2格式。
- 生成8个第二级微指数，其中直接对E6M2操作并返回BF16的定制倒数指令消除了显式除法。然后8个并行乘法比较操作产生E1_8。
- 计算16个第三级微指数。注意$2^{-E1}$简化为0.5或1。因此，可以实现乘法指令的特殊旁路模式来计算$BF16\times2^{-E1}$值。

**阶段3**计算64个组内元素：
- 将三级HiF4缩放因子应用于原始64个BF16输入。
- 将缩放结果量化为S1P2格式。如果舍入后的结果超出S1P2的可表示范围，应钳位到最近的可表示边界，同时保留符号。

BF16到HiF4转换中的所有舍入操作应使用round-half-to-even或round-half-away-from-zero。此外，由于E6M2没有次正规数，所提出的E6M2_REC_to_BF16转换指令可以仅使用一个由输入2位尾数索引的4条目查找表和简单的指数减法来高效实现，分别导出输出尾数和指数。同时，一些融合指令如乘法-比较和乘法-转换可以进一步加速HiF4转换过程。

## 3. 量化误差和点积

本节首先表征不同4位BFP格式的量化误差，然后分析HiF4和NVFP4的点积计算复杂度。

### 3.1 量化误差评估

我们生成了18个高精度高斯分布随机矩阵，大小为$1024 \times 1024$，每个矩阵均值为零，标准差$\sigma = 0.01 \times 2^x$，其中$x \in [0, 17]$。每个矩阵都转换为三种4位BFP格式。HiF4遵循上述算法。MXFP4采用文献中描述的方法。NVFP4采用E4M3缩放将每个组的峰值幅度归一化到6，即E2M1的可表示上限。由于只有NVFP4缺乏足够的动态范围并需要额外的基于软件的PTS，为了公平比较，准备了两个版本：直接转换和先将每个张量的峰值幅度缩放到2688然后量化为NVFP4的流水线。我们计算每种格式相对于原始高精度矩阵的均方误差（MSE），并相对于HiF4对结果进行归一化。

图3-1描绘了HiF4、MXFP4和NVFP4的量化误差。当数据值接近NVFP4的数值边界时，溢出和下溢导致量化误差显著增加。在格式转换之前应用PTS可以消除这种精度损失。相比之下，HiF4和MXFP4不需要PTS，因此不会产生额外的量化开销。排除NVFP4的波动，三种4位BFP格式的MSE比率保持稳定：

$$\text{HiF4 : NVFP4 : MXFP4} = 1 : 1.32 : 1.89$$

请注意，尽管高斯分布与神经网络中数据的集中性质相匹配，但在实际场景中量化误差可能会有所不同。实验结果作为分析不同4位BFP格式精度的定量参考。

### 3.2 点积评估

设A: $\{E6M2^{(A)}, E1_8^{(A)}, E1_16^{(A)}, S1P2_64^{(A)}\}$ 和B: $\{E6M2^{(B)}, E1_8^{(B)}, E1_16^{(B)}, S1P2_64^{(B)}\}$ 表示两个HiF4单元。A和B的点积应按如下方式计算：

$$\begin{align}
Dot(A, B)& = E6M2^{(A)} \times E6M2^{(B)} \times \\
&\sum_{i=1}^8 2^{(E1_8^{(A)}[i] + E1_8^{(B)}[i])} \times \\
&\sum_{j = 2i-1}^{2i} 2^{(E1_16^{(A)}[j] + E1_16^{(B)}[j])} \times \\
&\sum_{k = 4j-3}^{4j} (S1P2_64^{(A)}[k] \times S1P2_64^{(B)}[k])
\end{align}$$

在硬件中，并行执行K长度点积和累加的处理元素（PE）是矩阵计算单元的基本构建块，例如Nvidia GPU的Tensor Cores和Ascend NPU的Cube Cores。为了使4位BFP格式的计算能力相对于8位浮点格式翻倍，Tensor Cores和Cube Cores现在都要求PE支持64长度点积。在这些条件下，一对HiF4单元足以匹配PE输入宽度，因为它们的组大小恰好是64。相比之下，需要四对NVFP4单元才能在PE中支持64长度点积，因为它们的组大小只有16。

对于HiF4点积，第二级和第三级微指数可以在硬件中实现为简单的左移操作。根据实现策略，有很多机会将微指数吸收到与S1P2元素相关的计算中。在示例计算流程中，在乘法之前直接将第三级微指数吸收到S1P2元素中。这样，乘法器输入变为5位整数，可以表示为S2P2。类似地，NVFP4中的E2M1元素在乘法之前转换为5位整数（S3P1）。

在从64个乘积压缩到单个S12P4输出期间，HiF4采用纯整数运算，在累加树的最后阶段只需要一个小型浮点乘法器和一个大型整数乘法器。相比之下，NVFP4仅在从64个乘积归约到四个S10P2输出期间保留整数运算，之后需要四个小型浮点乘法器和四个大型整数乘法器。最后从四个部分结果累加到输出完全以浮点方式执行。因此，与NVFP4相比，HiF4消除了六个乘法器并简化了累加过程。

实际上，4位BFP格式集成到最初为16位（FP16和BF16）和8位（INT8和Float8）格式优化的现有点积单元中。尽管不同精度模式之间可以共享资源，但高精度格式不需要累加树内的中间和最终乘法器。因此，浮点元数据E6M2和E4M3引入的额外乘法器会产生额外的硬件开销。因此，对于64长度点积，HiF4仅占用NVFP4增量面积的约三分之一，并将功耗降低约10%。总之，HiF4实现了更高效的矩阵乘法面积和功耗实现。

## 4. 基于HiFloat4的语言模型推理

本节对HiF4和NVFP4格式在不同任务和LLM架构上进行了全面的训练后量化（PTQ）推理评估。

### 4.1 LLM的训练后量化

为了展示4位格式的固有精度，我们优先使用HiF4直接转换、NVFP4直接转换和NVFP4 + PTS方法进行LLM推理，如第3节所述。同时，为了表明许多现有的PTQ方法可以通过微小修改来提高HiF4的准确性，我们开发了一种基于vanilla GPTQ的定制PTQ方法，称为HiGPTQ，以利用HiF4 BFP格式的细粒度结构。

### 4.2 小型LLM实验

我们首先在参数大小从7B到14B的相对较小的LLM上评估我们的方法。

#### 模型

我们在各种LLM架构和模型规模上评估4位量化精度，包括：
- LLaMA2-7B
- LLaMA3-8B
- Qwen2.5-14B
- Mistral-7B

这些模型涵盖了广泛的架构设计，包括多头注意力（MHA）和分组查询注意力（GQA），以及多种形式的前馈网络（FFN）。

#### 数据集

我们使用一套广泛采用的LLM基准测试，包括：
- ARC-C(hallenge)
- ARC-E(asy)
- BoolQ
- HellaS(wag)
- Lam(bada)Op(enAI)
- Piqa
- WinoG(rande)
- MMLU

这些基准测试涵盖了广泛的任务，包括常识和物理推理、完形填空、代词/共指消解、事实验证和多领域知识评估。

#### 实现细节

本节中的实验均基于Nvidia GPU和华为Ascend NPU使用模拟的4位BFP格式进行。具体而言，在矩阵乘法之前，所有线性层张量（嵌入层和LLM头部层除外）仅从高精度格式转换为HiF4和NVFP4格式可以表示的格式。本节中报告的所有实验均在两个设备上并行进行。对于每个设备，我们使用不同的随机种子进行三次运行。最终结果是三次运行和两个设备上的平均推理精度，以确保随机方差最小化。为了公平比较，我们在统一框架内评估所有模型和量化设置，其中给定基准测试的所有实验都使用相同的提示模板进行LLM推理。

#### 实验结果与分析

表4-1和表4-2显示，HiF4（直接转换）在所有四个评估的LLM模型上始终优于先前最先进的NVFP4（直接转换）和NVFP4+PTS，表明所提出的HiF4构成了更准确的4位BFP格式。我们进一步观察到HiF4在直接转换下比NVFP4更加稳健，这归因于其更大的全局和合适的局部动态范围。例如，Mistral-7B表现出更广泛的数值分布，在这种情况下使用NVFP4进行直接转换推理会导致模型失败，精度下降到接近随机猜测水平，即推理崩溃。相比之下，HiF4在相同条件下实现了稳定的直接转换推理。此外，HiGPTQ在所有四个评估模型上进一步提高了HiF4的推理精度。值得注意的是，对于在训练期间优化了数值分布的Qwen2.5-14B模型，HiF4和HiGPTQ的组合甚至超过了BF16基线。

总之，所提出的HiF4格式表现出比NVFP4更高的固有精度和稳定性。许多成熟的PTQ方法，如GPTQ，可以通过微小修改来进一步提高HiF4的准确性。

## 5. 结论

本文提出了一种用于深度学习的新型4位BFP格式HiF4。在HiF4的设计背后，我们首先论证了在4位BFP格式设计中，具有3位有效位数的E1M2（S1P2）比具有2位有效位数的E2M1提供更高的精度上限。然后，我们成功发现将组大小增加到64并采用两级共享微指数（每值元数据开销为0.5位）在整体精度、量化复杂度和硬件效率之间提供了新的权衡。此外，我们精心设计了专用的全局基础缩放，提供足够的组间动态范围，能够直接支持训练和推理场景，同时提高可用组内动态范围的利用率。

数值分析表明，与最先进的NVFP4格式相比，HiF4在高斯分布数据上的MSE量化误差降低了24%。当64长度点积集成到最初为16位（FP16/BF16）和8位（INT8/Float8）精度优化的现有硬件点积单元中时，HiF4仅占用NVFP4增量面积的约三分之一，并将功耗降低约10%。最后，我们进行了广泛的LLM推理实验，证明HiF4在各种LLM架构和不同任务上始终比NVFP4实现更高的精度。未来的工作将展示所提出的HiF4格式的训练潜力。
