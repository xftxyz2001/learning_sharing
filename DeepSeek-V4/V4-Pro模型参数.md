# DeepSeek-V4-Pro 模型参数

以下信息整理自 DeepSeek-V4 中文版论文 README 的“模型设置”部分。

## 参数汇总

| 参数 | 数值 |
| --- | ---: |
| Transformer 层数 | 61 |
| 模型隐藏维度 $d$ | 7168 |
| 每个 MoE 层的共享专家数 | 1 |
| 每个 MoE 层的路由专家数 | 384 |
| 每个 MoE 层的专家总数（共享专家与路由专家合计） | 385 |
| 每 Token 激活的路由专家数 | 6 |
| 每 Token 实际使用的专家数（计入共享专家） | 7 |
| 每个专家的中间隐藏维度 | 3072 |
| CSA 索引器查询头数 $n_h^I$ | 64 |
| CSA 索引器头维度 $c^I$ | 128 |
| CSA 稀疏注意力 Top-K | 1024 |
| CSA 压缩率 $m$ | 4 |
| HCA 压缩率 $m'$ | 128 |
| CSA/HCA 查询头数 $n_h$ | 128 |
| 注意力头维度 $c$ | 512 |
| 查询压缩维度 $d_c$ | 1536 |
| 输出投影组数 $g$ | 16 |
| 中间注意力输出维度 $d_g$ | 1024 |
| 滑动窗口大小 $n_{\text{win}}$ | 128 |
| 多 Token 预测（MTP）深度 | 1 |
| $m$HC 扩展因子 $n_{\text{hc}}$ | 4 |
| Sinkhorn-Knopp 最大迭代次数 $t_{\text{max}}$ | 20 |
| 总参数量 | 1.6T |
| 每 Token 激活参数量 | 49B |

## 专家数量口径

- 论文明确给出的路由专家数量是 **384**。
- 加上 **1 个共享专家**，每个 MoE 层的专家总数为 **385**。
- 每个 Token 会激活 **6 个路由专家**；若计入始终参与计算的共享专家，则每个 Token 实际使用 **7 个专家**。

## 原文引用

> 我们将 Transformer 层数设置为 61，隐藏维度 $d$ 设置为 7168。

> 每个MoE层由1个共享专家和384个路由专家组成，其中每个专家的中间隐藏维度为3072。在路由专家中，每个词元将激活6个专家。

> 在此配置下，DeepSeek-V4-Pro总共包含1.6T参数，其中每个词元激活49B个参数。
